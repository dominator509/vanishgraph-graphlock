STACK FINALISED (ARCHITECTURE.md section 4 is authoritative, DECISIONS.md holds the ADRs):
- ADR-016 Temporal REMOVED. Durable work runs on a Postgres-native queue behind a
  JobQueue port, enqueued inside the same transaction as the state transition that
  requires it. Temporal was a second stateful cluster and the single largest
  self-hosting barrier for an open-source project; the state machine already lives in
  our domain and in PostgreSQL. Making the enqueue transactional also removes a
  dual-write inconsistency class rather than managing it.
- ADR-007 Next.js REMOVED. The UI is a Vite + React SPA with TanStack Router/Query.
  Every portal surface is authenticated, so SSR buys nothing, while a server/client
  boundary is a way to move subject PII to the browser by mistake.
- ADR-008 Kysely + SQL-first migrations rather than an ORM, because RLS depends on
  transaction-scoped SET LOCAL app.tenant_id and policies/triggers cannot be expressed
  through a schema DSL.
- Also locked: Zod, Testcontainers, pgvector, Keycloak (OIDC-generic), S3 API with
  SeaweedFS as the self-hosted default, Valkey as cache only.
