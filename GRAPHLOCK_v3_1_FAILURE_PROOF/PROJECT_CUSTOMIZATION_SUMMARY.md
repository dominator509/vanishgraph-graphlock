## How to use

1. Give the full ZIP to a capable coding/reasoning agent.
2. Tell it to read `GRAPHLOCK_v3_1_BOOTSTRAP_LAUNCHER.md` and the master prompt in full.
3. In the current bundle, `MODE: FORGE_ONLY` means it should generate and validate the complete project-specific 6LAYER Blueprint Pack but not begin writing the application.
4. Review the generated blueprint and external gates.
5. When you intentionally want autonomous construction, change the launcher mode to `FORGE_AND_EXECUTE` or explicitly instruct the agent to do so.
