##### 4 · TEST METHODOLOGY — API Key Exposure Testing
- Build the client locally and grep built artifacts for embedded keys.
- Review server logging configuration to confirm Authorization headers and key-bearing parameters are redacted.
- Verify keys are transmitted via Authorization header only (not query string or URL path).
- Confirm keys are scoped (least privilege) and have a documented rotation schedule.
- Minimize false positives by confirming each leaked string is an active key rather than a placeholder/test value.
