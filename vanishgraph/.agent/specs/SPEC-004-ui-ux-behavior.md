# SPEC-004 UI/UX Behavior

The responsive customer and operator portals provide onboarding, authorization, exposure inventory, action queue, case timeline, proof viewer, recheck calendar, coverage report, and deletion controls. Status labels show uncertainty and evidence links.

WCAG 2.2 AA applies: keyboard operation, semantic structure, focus, errors, live status, non-color status, reduced motion, high contrast, and text alternatives for evidence. No browser analytics receives PII.

Acceptance is through the real authenticated entrypoint with loading, empty, error, unauthorized, and success states plus manual assistive-technology validation as an external gate.
