# DONE LAW

Narrative completion is prohibited. Every scope is complete only when all applicable DOD clauses pass with current evidence. The canonical 42 clauses are in DOD_REGISTRY.csv and are immutable control data. PASS without evidence, N/A without repository evidence, or blocked-as-success is invalid.

## Status taxonomy
DONE_VERIFIED, DONE_WITH_ACCEPTED_EXCEPTION, CLOSED_BLOCKED, CLOSED_NOT_APPLICABLE, FAILED_VALIDATED, SUPERSEDED_BY_CHANGE_CONTROL.

Before closure ask: Could a non-functional or fake implementation pass this gate? If yes, the gate is too weak and closure is prohibited.
